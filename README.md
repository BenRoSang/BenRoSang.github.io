# Zar Hlei Sang — Developer Portfolio

A lightweight portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Preview locally

Run a simple static server from this folder:

```bash
python3 -m http.server 5174
```

Then open `http://localhost:5174`.

## Easy updates

- Personal and project copy: `index.html`
- Colors and layout: `style.css`
- Availability text: `portfolioConfig` at the top of `script.js`
- Profile image: replace `assets/images/profile.jpg` using the same filename
- CV: replace `assets/documents/Zar-Hlei-Sang-CV.pdf` using the same filename
- Project images: replace the matching files inside `assets/images/`

No build command or package installation is required.
